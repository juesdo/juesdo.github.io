0x01 前言1. 什么是序列化与反序列化？ 序列化 (Serialization)： 把内存中的 Java 对象转换成“字节序列”（一串 0 和 1）的过程。这就像是把你组装好的立体积木城堡拆解、编号，并整齐地装进盒子里。 反序列化 (Deserialization)： 把字节序列重新恢复成 Java 对象的过程。这就像是打开盒子，照着编号把积木重新拼回那个立体的城堡。 2. 为什么需要它？ 持久化保存（存档）： 内存断电即焚。如果你想把游戏里玩家的当前属性（生命值、装备等对象）保存到硬盘上，就需要序列化。 网络传输： 网络电缆里只能跑 0 和 1 的字节流，不能直接塞进去一个立体的 Java 对象。所以得先“压扁”（序列化）发送，接收端再“充气”（反序列化）还原。 3.
